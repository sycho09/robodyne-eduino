# AI Agent Rules for AIoT_AI-Trainer-claude-vision-studio

## Git Commit Rules
When writing commit messages, always follow the Conventional Commits format:
`type(optional scope): short summary`

### Types:
- **feat**: 새로운 기능 추가
- **fix**: 버그 수정
- **refactor**: 코드 리팩토링 (기능 변화 없이 코드 구조만 변경)
- **style**: 코드 포맷팅, 세미콜론 등 스타일 수정 (로직 변경 없음)
- **docs**: 문서 수정 (README, 주석 등)
- **chore**: 빌드 업무, 패키지 매니저 설정, 기타 자잘한 작업
- **test**: 테스트 코드 추가 및 수정

### Format Guidelines:
- 요약(summary)은 명령문(현재 시제)으로 작성하거나 명사형으로 끝맺습니다.
- 첫 글자는 가능하면 소문자로 시작합니다.
- 끝에 마침표(.)를 붙이지 않습니다.
- 한 줄로 간결하게 작성하는 것을 원칙으로 하되, 필요시 본문(body)에 상세 내용을 적습니다.
