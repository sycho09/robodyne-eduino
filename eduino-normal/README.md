# Eduino AI — 일반모드 (6개 AI 학습 코스)

브라우저에서 바로 돌아가는 교육용 AI 학습 코스 6종입니다. 설치·가입 없이 카메라·소리·데이터로 학생이 직접 AI를 학습시키고 결과를 눈으로 확인합니다.

| 코스 | 대상 |
| --- | --- |
| 비전 · 영상처리 AI | 초등~중등 |
| 제스처 · 동작 AI | 초등~중등 |
| 데이터 · 예측 AI (AIoT) | 중·고~대학 |
| 텍스트 · 언어 AI | 중등~대학 |
| 생활 속 인식 AI | 초등~중등 |
| 머신러닝 개념 실험실 | 고교~대학 |

## 실행 방법

### 1. 데스크톱 앱으로 실행 (권장)

```bash
npm install
npm run app
```

`npm install` 은 처음 한 번만 하면 됩니다 (Electron 내려받기에 몇 분 걸릴 수 있습니다).

### 2. 웹 서버로 실행

`start-app.bat` 을 더블클릭하면 로컬 서버가 뜨고 브라우저가 열립니다.

## 시작 화면

`platform/index.html` — 코스 카탈로그. 카드를 누르면 코스 소개(학습 흐름·동작 미리보기)로, 거기서 실제 학습 화면으로 들어갑니다.

## 요구 사항

- 웹캠이 있는 PC 또는 태블릿
- 크롬 등 최신 브라우저
- 카메라를 쓰는 코스는 `https` 또는 `localhost` 접속 필요 (데스크톱 앱은 해당 없음)

데이터는 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.
