정답(색) 칠해서 데이터 만들기

먼저 색(=정답)을 고르고 그래프를 클릭해 점을 찍어요. AI는 이 ‘정답이 붙은’ 점들을 보고 색을 나누는 경계를 배웁니다 — 이게 지도학습이에요.

원리와 활용

AI가 데이터를 나누는 기준

결정 경계란?

AI가 ‘여기부터는 빨강, 저기부터는 파랑’이라고 나눈 선(경계)이에요. 새 데이터가 어느 쪽에 있는지로 분류를 결정합니다.

일반화 vs 과적합

복잡도가 낮으면 경계가 매끈해 새 데이터에도 잘 맞아요(일반화). 너무 높으면 점 하나하나에 억지로 맞춰 울퉁불퉁해지는데, 이게 과적합 — 시험엔 강해도 실전엔 약해요.

왜 중요할까?

모든 AI 모델은 ‘외운 것’이 아니라 ‘일반화’해야 실제 데이터에서 잘 작동해요. 과적합을 피하는 건 머신러닝의 핵심 과제예요.

실험 흐름라벨 칠하기→경계 학습→복잡도 조절→일반화↔과적합 비교

같은 점, 두 가지 방법

똑같은 점들을 ① 정답(색)을 알려주고 배우는 방법과 ② 정답 없이 비슷한 것끼리 묶는 방법으로 비교해 봐요.

무엇이 다를까?

버튼을 바꿔가며 왼쪽 그래프가 어떻게 달라지는지 보세요.

지도학습

정답표(라벨)가 있어요. 사람이 ‘이건 빨강, 저건 파랑’이라 알려주면 AI가 경계를 배워 새 점도 분류해요.

예) 스팸/정상 메일 분류, 사진 속 동물 이름 맞히기

비지도학습

정답표가 없어요. AI가 비슷한 것끼리 스스로 묶어요(군집화). 무리에 ‘이름’은 사람이 나중에 붙여요.

예) 고객을 취향별로 자동 분류, 비슷한 뉴스 묶기

원리와 활용

두 가지 학습 방식의 차이

지도학습

정답표(라벨)가 있어요. ‘이건 빨강, 저건 파랑’을 알려주면 AI가 경계를 배워 새 점도 분류해요. → 분류·예측에 강함.

비지도학습

정답표가 없어요. AI가 위치만 보고 비슷한 것끼리 스스로 묶어요(군집화). 무리의 ‘이름’은 사람이 나중에 붙입니다. → 군집·요약.

어디에 쓰일까?

지도: 스팸 분류·사진 인식·예측. 비지도: 고객 취향 그룹·비슷한 뉴스 묶기·이상치 탐지. 상황에 맞게 골라 써요.
