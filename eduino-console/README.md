# Eduino AI — 비전 콘솔

게임기 톤의 허브에서 AI 비전 스테이지를 골라 실행하는 수업 도구입니다. 설치·가입 없이 카메라만 있으면 바로 돌아갑니다.

## 화면 흐름

`platform/index.html` (시작페이지) → **🎮 비전 콘솔** 버튼 → `entry.html` 모드 선택(체험 · 수업 개설 · 수업 참여) → 허브(스테이지 맵 / 카드 캐러셀) → 각 스테이지

## 구성

**TRACK 01 · 기본기능 체험** — 학습 없이 클릭 한 번으로 작동시켜 관찰합니다.

| 스테이지 | 내용 |
| --- | --- |
| 객체 탐지 | COCO-SSD 로 90종 사물을 실시간 인식 |
| 얼굴 검출 | BlazeFace 로 얼굴 위치·눈·코·입 검출 |
| 뼈대 검출 | MoveNet 으로 관절 17곳 추적 |
| 색상 추적 | RGB 임계값으로 특정 색만 남기기 |
| 영상 효과 | 흑백·반전·엣지 필터와 움직임 감지 |

**TRACK 02 · 직접 제작** — 데이터를 모아 학습시키고 결과를 평가합니다. 이미지 분류 · 음성 분류 · 동작 분류.

## 실행 방법

### 1. 데스크톱 앱으로 실행 (권장)

```bash
npm install
npm run app
```

`npm install` 은 처음 한 번만 하면 됩니다 (Electron 내려받기에 몇 분 걸릴 수 있습니다).

### 2. 웹 서버로 실행

`start-app.bat` 을 더블클릭하면 로컬 서버가 뜨고 브라우저가 열립니다.

## 배포본 만들기 (빌드)

```bash
npm run dist
```

`dist/Eduino AI 비전 콘솔 1.0.0.exe` (약 97MB) 하나가 만들어집니다. 설치가 필요 없는 포터블 실행파일이라 이 파일만 전달하면 됩니다.

`dist/` 는 `.gitignore` 에 있어 저장소에 포함되지 않습니다. 클론만으로는 실행파일이 따라오지 않으니 각자 빌드해야 합니다.

### 빌드 전 · Windows 개발자 모드를 켜세요

켜지 않으면 빌드가 아래 오류로 **실패합니다**.

```
ERROR: Cannot create symbolic link : 클라이언트가 필요한 권한을 가지고 있지 않습니다
```

electron-builder 가 내려받는 코드 서명 도구(`winCodeSign`) 안에 macOS 용 심볼릭 링크가 들어 있는데, Windows 는 심볼릭 링크 생성에 특권을 요구하기 때문입니다. **저장소 설정으로는 해결되지 않는 PC 설정 문제입니다.**

> 설정 → 개인 정보 및 보안 → 개발자용 → **개발자 모드** 켜기

관리자 권한 터미널에서 `npm run dist` 를 한 번 돌려도 됩니다. 도구가 캐시에 정상적으로 풀리고 나면 그 뒤로는 일반 터미널에서도 빌드됩니다.

### 알려진 미비점 · 앱 아이콘

`package.json` 의 `build` 에 `win.icon` 이 없어 **기본 Electron 아이콘**으로 빌드됩니다. 정식 배포 전에 처리해야 합니다.

- 256×256 이상(권장 512×512) 정사각 PNG 를 `build/icon.png` 에 두면 electron-builder 가 자동으로 인식합니다.
- 현재 저장소에 있는 이미지는 `favicon.png`(64×64) · `apple-touch-icon.png`(180×180) 뿐이라 크기가 모자랍니다. 새로 준비해야 합니다.
- 아이콘은 위 개발자 모드 문제를 먼저 풀어야 반영됩니다. 아이콘을 새겨 넣는 `rcedit` 도구가 바로 그 `winCodeSign` 패키지 안에 들어 있기 때문입니다.

## 요구 사항

- 웹캠이 있는 PC 또는 태블릿
- 크롬 등 최신 브라우저
- 웹 서버로 쓸 때는 `https` 또는 `localhost` 접속 필요 (카메라 권한). 데스크톱 앱은 해당 없음

데이터는 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.
