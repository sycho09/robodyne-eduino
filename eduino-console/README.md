# Eduino AI — 비전 콘솔

게임기 톤의 허브에서 AI 비전 스테이지를 골라 실행하는 수업 도구입니다. 설치·가입 없이 카메라만 있으면 바로 돌아갑니다.

## 화면 흐름

`platform/index.html` (시작페이지) → **🎮 비전 콘솔** 버튼 → `entry.html` 모드 선택(체험 · 수업 개설 · 수업 참여) → 허브(스테이지 맵 / 카드 캐러셀) → 각 스테이지

## 구성

**TRACK 01 · 기본기능 체험** — 학습 없이 클릭 한 번으로 작동시켜 관찰합니다.

| 스테이지 | 내용 |
| --- | --- |
| 객체 탐지 | COCO-SSD 로 90종 사물을 실시간 인식 |
| 얼굴 검출 | BlazeFace 로 얼굴 위치·눈·코·입 검출 |
| 뼈대 검출 | MoveNet 으로 관절 17곳 추적 |
| 색상 추적 | RGB 임계값으로 특정 색만 남기기 |
| 영상 효과 | 흑백·반전·엣지 필터와 움직임 감지 |

**TRACK 02 · 직접 제작** — 데이터를 모아 학습시키고 결과를 평가합니다. 이미지 분류 · 음성 분류 · 동작 분류.

## 실행 방법

### 1. 데스크톱 앱으로 실행 (권장)

```bash
npm install
npm run app
```

`npm install` 은 처음 한 번만 하면 됩니다 (Electron 내려받기에 몇 분 걸릴 수 있습니다).

### 2. 웹 서버로 실행

`start-app.bat` 을 더블클릭하면 로컬 서버가 뜨고 브라우저가 열립니다.

## 요구 사항

- 웹캠이 있는 PC 또는 태블릿
- 크롬 등 최신 브라우저
- 웹 서버로 쓸 때는 `https` 또는 `localhost` 접속 필요 (카메라 권한). 데스크톱 앱은 해당 없음

데이터는 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.
