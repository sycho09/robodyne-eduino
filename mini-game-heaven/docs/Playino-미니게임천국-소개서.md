## 1. 제품 소개
마스코트 **EDDIE**와 함께 8개 센서를 미니게임으로 익히고, **응용·심화**로 나만의 작품까지 완성하는 STEAM 피지컬 코딩 키트.

- **핵심 컨셉** — 센서 1개 = 전용 미니게임 1개. 이론관(원리) + 체험관(게임).
- **대상** — 초등 고학년 ~ 중등 (가정·방과후·학원·학교 교구)
- **학습 환경** — Chrome / Edge (PC·노트북·크롬북), USB 연결. 설치 불필요, 접속 링크/코드.
- **구조** — 메달 수집 → 진척 100% 달성 시 졸업.

## 2. 학습 구성 (3단계)
| 단계 | 성격 | 내용 |
|---|---|---|
| **1단계 개별학습** | 센서 원리·제어 | 센서별 미니게임 **8개** |
| **2단계 응용학습** | 감지→동작 (피지컬 컴퓨팅 핵심) | 입력+출력 조합 작품 **4개** |
| **3단계 심화학습** | 창작 (브랜드 클라이맥스) | 나만의 미니 게임기 **1개** (졸업 작품) |

## 3. 구성품 리스트
**공통** — Arduino Uno(호환) · Grove Base Shield · USB 케이블 · Grove 케이블 · 수납 박스 · 퀵스타트 가이드(QR)

**센서 8종 (출력 4 · 입력 4)**
| # | 센서 | 입/출력 | 대표 게임 |
|---|---|---|---|
| 1 | LED ×3 (빨강·노랑·초록) | 출력 | 반짝반짝 라이트쇼 |
| 2 | 부저 (Passive) | 출력 | 멜로디 연주단 |
| 3 | RGB LED | 출력 | 무지개 물감놀이 |
| 4 | 서보 모터 (SG-90) | 출력 | 행운의 룰렛 |
| 5 | 조도센서 (CDS) | 입력 | 손그림자 마술 |
| 6 | 버튼 (택트) | 입력 | 두더지 잡기 |
| 7 | 조이스틱 | 입력 | 별★줍기 대모험 |
| 8 | 초음파 거리센서 | 입력 | 손 거리 마법 |

> Grove 기반(무납땜·케이블식)으로 초·중등도 쉬운 세팅. 무선(BLE) 모듈은 **별매 액세서리**로 추후. 단가·모델·인증(KC)은 별도 확정.

## 4. 커리큘럼

### ① 개별학습 — 센서별 미니게임 8
| 센서 | 게임 | 장르 / 학습 |
|---|---|---|
| LED | 반짝반짝 라이트쇼 | 리듬 · 디지털 출력/타이밍 |
| 부저 | 멜로디 연주단 | 리듬 · tone/주파수 |
| RGB | 무지개 물감놀이 | 색 맞추기 · PWM 색 혼합 |
| 서보 | 행운의 룰렛 | 타이밍 · 각도 제어 |
| 조도(CDS) | 손그림자 마술 | 반응+생존 · 아날로그 입력(빛) |
| 버튼 | 두더지 잡기 | 연타/반응 · 디지털 입력 |
| 조이스틱 | 별★줍기 대모험 | 이동/수집 · 2축 아날로그 입력 |
| 초음파 | 손 거리 마법 | 거리 조절 · 비접촉 거리 측정 |

### ② 응용학습 — 감지→동작 조합 4
| 작품 | 센서 조합 | 배우는 핵심 |
|---|---|---|
| 스마트 홈 미니 | 조도+초음파+서보+RGB+부저 | 어두우면 조명 ON, 사람 다가오면 문 열림+알림 |
| 비접촉 테레민 | 초음파+부저 | 손 거리 → 음정 (아날로그 매핑) |
| 우주 슈팅 | 조이스틱+RGB/LED | 이동·발사 (입력으로 출력 제어) |
| 자동 관문 | 버튼/초음파+서보 | 감지 시 모터 작동 |

### ③ 심화학습 — 졸업 작품 1
| 작품 | 센서 조합 | 내용 |
|---|---|---|
| 🎮 나만의 미니 게임기 | 조이스틱+버튼+RGB+부저 | 아두이노가 게임 컨트롤러가 되어, 배운 센서로 직접 미니게임을 완성 |

## 5. 한눈에 보기
