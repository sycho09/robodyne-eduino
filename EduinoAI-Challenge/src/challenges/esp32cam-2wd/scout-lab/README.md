# RC카 스마트탐사 — 교실 탐사대

`scout-lab` · 모드 3 · 매니페스트 판 1.0.0

> 카메라로 보고, 배우고, 배운 것으로 알아본다

## 이 챌린지가 쓰는 파일

| 파일 | 갈래 | 무엇 |
| --- | --- | --- |
| `challenge.json` (이 폴더) | **전용** | 이 챌린지의 전부 — 4분할 구성 · 단계 · 안전값 · 기기 주소. 스타터 코드는 없다 |
| `src/ui/pages/scout.js` | **사실상 전용** | 탐사 화면. 다른 챌린지는 이 페이지를 열지 않는다 |
| `src/ui/scout/` 10개 | **사실상 전용** | 어댑터 · 4분할 · 조종 · 학습 · 분류 · 결과 · 로그 · 단계 · 제출 |
| `src/ui/styles/scout.css` | **사실상 전용** | 탐사 화면의 3열 배치와 상태 줄 |
| `src/kits/esp32cam-2wd.json` | 공용 | 바퀴 속도 · 데드존 · 기본 PWM · 핀 배치 |
| `src/engine/` · `src/runtime/` · `src/ui/` | 공용 | 물리 · 컴파일 · 화면. 챌린지마다 복사하지 않는다 |

전용은 이 챌린지만 쓰는 것이고, 공용은 다른 챌린지도 같은 것을 쓴다.
공용을 고치면 **모든 챌린지가 함께 바뀐다** — 이 챌린지만 바꾸고 싶으면 매니페스트를 고친다.

## 이 챌린지가 쓰는 에셋

그림은 슬롯 이름으로만 부른다. 이름 → 파일 대응은 `assets/assets.manifest.json` 한 곳이 갖는다.
**에셋 파일은 챌린지별 폴더로 가르지 않는다**(57-G — 굽는 도구와 봉인이 폴더 이름에 묶여 있다).
담당자가 알아야 할 "이 챌린지가 무엇을 쓰는가" 는 아래 목록이 답한다.

| 슬롯 | 갈래 | 무엇 |
| --- | --- | --- |
| — | — | 이 챌린지는 에셋 슬롯을 쓰지 않는다. 화면에 나오는 것은 카메라가 지금 보내는 프레임뿐이다 |

## 매니페스트에서 무엇을 고치면 무엇이 바뀌나

| 고치는 자리 | 화면에서 바뀌는 것 |
| --- | --- |
| `scene.ui.quad` | 4분할 네 칸이 각각 무엇을 보여줄지. 칸 이름 · 효과 · 칸 안 설명 전부 |
| `scene.ui.view_px · process_px · sample_px` | 화면에 그리는 크기와 학습이 실제로 보는 크기 |
| `stages` | 왼쪽 단계 목록과 각 단계의 문구 · 넘어가는 조건 |
| `camera_sources` · `source_labels` | 고를 수 있는 입력(웹캠 · 기기 · 시뮬)과 그 이름 |
| `device` | 실물 보드의 주소 규칙 — 포트 · 경로 · 재전송 간격 · 타임아웃 |
| `safety` | 정지까지의 시간(deadman) · 연결 끊김 판정 |
| `log` · `path` · `submit` | 로그 줄 · 이동 자취 · 제출 화면의 구성 |
| `allowed_api` | 학생에게 열리는 API. 여기 없는 것을 부르면 막힌다 |

이 챌린지에는 트랙 · 랩타임 · 채점 · 코드 에디터가 없다. 그래서 다른 챌린지의
`scene.track` · `scoring` · `starter_code` 에 해당하는 자리도 없다.

## 건드리면 안 되는 것

**`scene.ui.quad` 의 4분할 구성** — 화면 넷이 무엇을 보여줄지를 전부 여기서 정한다. 코드에 목록이 없다

**`device` 의 `deadman_ms` · `link_loss_ms`** — 실물 안전값이다. 지금 1200·1500 은 실물 없이 정한 값이라 실물로 재 본 뒤 다시 본다(백로그)

**영상·원본 이미지** — 저장하지도 보내지도 않는다. 원칙 7 — 예외 없음

**물리 · 랩타임 · 결정론 코드** — `src/engine/` 은 어느 챌린지에서도 고치지 않는다. 고정 10ms tick · 고정 seed · 난수 없음이 기록을 비교 가능하게 만드는 근거다

**공용 셸과 검사** — 챌린지마다 복사하지 않는다. 한 벌만 둔다(14차)

**에셋** — 그림은 슬롯 이름으로만 부른다. 코드로 그리지 않는다(데이터 오버레이만 예외)

## 이 챌린지만의 검사 · 기준값

- 랩 tick 기준값 없음
- 브라우저 검사가 전부 훑는다 — 렌더 · 콜드 캐시 · 화면 · 세로 넘침 · 기록 있는 상태 · 첫 진입 · 옛 코드 · 안내 짚기
- 건너뛰는 검사 6종 — 렌더 · 콜드 캐시 · 화면 · 기록 있는 상태 · 첫 진입 상태 · 옛 코드 있는 상태
  - 사유: 57차 스마트탐사. 트랙·랩타임·채점·코드 에디터가 없어 이 검사들이 보는 화면 요소가 아예 존재하지 않는다. 게다가 실물 카메라가 있어야 프레임이 들어오는데 헤드리스에는 카메라가 없다. 목록 검사(catalog)에는 그대로 등록돼 있어 허브에서 빠지면 잡힌다. 57차 보강1: 세로 넘침은 카메라가 없어도 잴 수 있어 예
- 배경 밝기 기준값 `.color-baseline.json` 은 '렌더' 검사가 통과했을 때만 다시 적는다
