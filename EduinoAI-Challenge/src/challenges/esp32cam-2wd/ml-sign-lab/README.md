# RC카 테마학습제어 — 표지판 학습 실험실

`ml-sign-lab` · 모드 2 · 매니페스트 판 1.0.0 · **허브 목록에서 내려 둔 챌린지**

> 정지·서행·진행 세 표지판을 직접 학습시킨다. 샘플을 골고루 담을수록 잘 맞힌다

## 이 챌린지가 쓰는 파일

| 파일 | 갈래 | 무엇 |
| --- | --- | --- |
| `challenge.json` (이 폴더) | **전용** | 이 챌린지의 전부 — 수치 · 문구 · 규칙 · 스타터 코드 |
| 에셋 슬롯 `slot:track.square` | 공용 | 코스 그림 |
| 에셋 슬롯 `slot:car.2wd` | 공용 | RC카 그림 |
| 에셋 슬롯 `slot:track.iso.square-1200` | **전용** | 배경 그림 |
| 안내 그림 슬롯 `slot:guide.ml-sign-lab.1~4` | **전용** | 가이드라인 팝업의 그림 |
| `src/kits/esp32cam-2wd.json` | 공용 | 바퀴 속도 · 데드존 · 기본 PWM · 핀 배치 |
| `src/engine/` · `src/runtime/` · `src/ui/` | 공용 | 물리 · 컴파일 · 화면. 챌린지마다 복사하지 않는다 |

전용은 이 챌린지만 쓰는 것이고, 공용은 다른 챌린지도 같은 것을 쓴다.
공용을 고치면 **모든 챌린지가 함께 바뀐다** — 이 챌린지만 바꾸고 싶으면 매니페스트를 고친다.

## 이 챌린지가 쓰는 에셋

그림은 슬롯 이름으로만 부른다. 이름 → 파일 대응은 `assets/assets.manifest.json` 한 곳이 갖는다.
**에셋 파일은 챌린지별 폴더로 가르지 않는다**(57-G — 굽는 도구와 봉인이 폴더 이름에 묶여 있다).
담당자가 알아야 할 "이 챌린지가 무엇을 쓰는가" 는 아래 목록이 답한다.

| 슬롯 | 갈래 | 무엇 |
| --- | --- | --- |
| `slot:car.2wd` | 킷 공용 | RC카 탑뷰 |
| `slot:track.iso.square-1200` | **전용** | 배경 그림 한 장 |
| `slot:track.square` | 공용 9종 | 코스 바닥 |
| `slot:guide.ml-sign-lab.1~4` | **전용** | 가이드라인 팝업 그림 4장 |

## 매니페스트에서 무엇을 고치면 무엇이 바뀌나

| 고치는 자리 | 화면에서 바뀌는 것 |
| --- | --- |
| `scene.track.center_side_mm · width_mm` | 코스의 크기와 폭. 트랙 그림과 이탈 판정이 함께 바뀐다 |
| `scene.spawn` | 출발 위치와 방향 |
| `scene.checkpoints · lap` | 한 바퀴로 인정하는 순서. 구간 시간이 여기서 갈린다 |
| `scene.assets.background` | 배경 그림 한 장(슬롯 이름). 그림 파일을 코드가 알지 않는다 |
| `scene.ui.goal_banner` | 화면 위 네 칸 문구 — 목표 · 제한 시간 · 실패 조건 · 기록 인정 |
| `scene.ui.advice` | 결과 카드의 조언 문장 틀. {값} 자리는 엔진이 채운다 |
| `scene.ui.api_doc` | [코드 설명] 칸에 뜨는 API 한 줄 설명 |
| `scene.ui.words` | 같은 값을 부르는 말(돈 바퀴 · 코스 벗어남 …) |
| `scene.rules.tune` | 튜닝 표에 뜨는 변수 이름과 설명. 스타터의 이름과 같아야 한다 |
| `starter_code.source` | 학생이 처음 보는 코드. 바꾸면 version 을 올린다 |
| `starter_code.version` | 올리면 손대지 않은 학생 코드는 새 판으로 바뀌고, 손댄 코드는 배너만 뜬다 |
| `allowed_api` | 학생에게 열리는 API. 여기 없는 것을 부르면 에디터가 막는다 |
| `rules.offtrack · timeout · penalty` | 실패 조건과 페널티 |
| `record.fields` | 기록에 함께 남길 것 — lap_total · lap_splits · path_image |
| `guide[].target.anchor` | 안내가 짚을 코드 줄. find 문자열이 스타터에 실제로 있어야 한다 |

## 건드리면 안 되는 것

**허브에서 내려 둔 상태** — 51차에 내렸다. 스마트시티와 성격이 겹친다

**`ml` 설정** — 학습 파이프라인의 수치가 전부 여기 있다. 코드가 아니라 데이터다

**물리 · 랩타임 · 결정론 코드** — `src/engine/` 은 어느 챌린지에서도 고치지 않는다. 고정 10ms tick · 고정 seed · 난수 없음이 기록을 비교 가능하게 만드는 근거다

**공용 셸과 검사** — 챌린지마다 복사하지 않는다. 한 벌만 둔다(14차)

**에셋** — 그림은 슬롯 이름으로만 부른다. 코드로 그리지 않는다(데이터 오버레이만 예외)

## 이 챌린지만의 검사 · 기준값

- 랩 tick 기준값 없음
- 허브 목록에서 내려 둔 챌린지라 브라우저 검사가 훑지 않는다. 대신 목록 검사(catalog)의 예외 목록 `catalog.allow.json` 에 이름과 사유가 남아 있다
- 배경 밝기 기준값 `.color-baseline.json` 은 '렌더' 검사가 통과했을 때만 다시 적는다
