# 참고 자료

## kit-esp32cam-2wd.png (미첨부)

교구 실물 사진. 모델링 근거 자료다.

**아직 리포에 없다.** 사진은 채팅으로 전달됐지만 작업자(에이전트)가 첨부 이미지의 파일 데이터에
접근할 수 없어 커밋하지 못했다. 기획자가 이 경로에 직접 올리면 된다.

모델링은 사진을 눈으로 확인한 아래 분석에 근거해 진행했다.

- 섀시: 원형 검정 아크릴, 반광(주변 반사 뚜렷), 앞쪽 슬롯 절개
- 바퀴: 노란 허브 + 검정 고무 타이어 2개, 지그재그 트레드, 섀시 좌우로 돌출
- 상단 뒤: 검정 배터리팩(직육면체, 측면 케이블 인출)
- 중앙: L298N — 초록 기판 + 파란 나사 터미널 2개 + 은색 방열판
- 앞쪽: 검정 PCB 컨트롤 보드(핀헤더, 주황/노랑 부품) + 검정 막대 안테나
- 배선: 회색 리본 + 빨강/검정 전원선
- 볼캐스터: 사진 각도에서 가려짐. 전방에 있는 것으로 보고 모델링
