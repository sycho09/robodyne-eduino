챌린지 디지털트윈 · 결과보고 02

재생 정상화 + 화면 가독성

재생이 목표의 1/70로 느렸던 원인은 프레임당 tick 상한이었습니다. 경과시간 기준으로 바꿔 저사양 환경에서도 98%를 회복했고, 트랙·계기판 가독성과 코드 보존까지 마쳤습니다. 아래 논의포인트 7건에 결정을 주시면 다음 차수로 넘어갑니다.

2026-08-21 브랜치 main 파트 1~5 완료 결정 대기 7건
각 섹션 오른쪽 버튼으로 부분만 복사할 수도 있습니다.

01이번 차수 요약

  • 완료재생 속도 [P0] — 실시간 1배속(초당 100 tick) 회복, 배속 1x/2x/4x 추가
  • 완료트랙 렌더링 — 주행 대역만 밝게 반전, 중심선 점선, START/FINISH·CP 라벨
  • 완료계기판 — 세그먼트처럼 보이던 대시 표기 제거, 판독 우선 대형 숫자
  • 완료좌측 컬럼 — 에디터 자동 줄바꿈, 오류 0건 시 패널 접힘, 상태 배지 계기판으로 이동
  • 완료코드 보존 — 코드·시도 이력 localStorage 저장, 새로고침 후 복원

원인은 (a) 구조적 문제가 근본이었습니다. 프레임 간 경과시간을 20ms로 잘라 누산해 프레임당 최대 2 tick이 상한이 되어 있었고, 저프레임일수록 정비례해 느려졌습니다. (b) 백그라운드 탭의 rAF 정지는 이를 극단으로 밀어붙인 증폭 요인입니다.

03논의포인트 — 결정 주셔야 진행됩니다

D1
GitHub 기본 브랜치를 main으로 미완료 · 직접 조작 필요

현재 default가 claude/challenge-…라 Vercel이 그 브랜치를 Production으로 잡고 있습니다. 변경 API가 제 도구에 없습니다.

  1. GitHub 리포 → Settings → General → Default branch의 ⇄ 아이콘 → main → Update
  2. Code 탭 → Branches → claude/challenge-… 삭제 (내용 동일, 잃는 것 없음)
D2
Vercel Production Branch를 main으로 미완료 · 직접 조작 필요

프로젝트 → Settings → Git → Production Branch를 main으로 저장 후 최신 배포 Redeploy. D1과 함께 처리해야 합니다.

D3
이번 차수에 제가 판단한 6건 승인 승인 대기

A 밀린 시뮬 시간 상한 1000ms · B 빈 값 표기를 0.000/"기록 없음"으로(대시가 세그먼트처럼 보였음) · C 대역 안쪽·바깥 동일 톤 · D 저장 가능 여부 칩 표시 · E 줄번호 미러 측정 · F 체크포인트 명명 START/FINISH·CP1~3

권장: 전체 승인. 되돌리는 비용은 모두 낮습니다.

D4
이탈 처리 최종 규칙 1차부터 미확정

현재는 지시대로 "이벤트 발생 + 카운터"만 있고 주행은 계속됩니다. 선택지: 현행 유지 / 랩타임 페널티 부여 / 일정 횟수 초과 시 시도 종료.

권장: 현행 유지. 모드2·3의 난이도 곡선이 정해진 뒤 함께 결정하는 편이 안전합니다.

D5
실패 판정 · 시도 종료 규칙 1차부터 미확정

스키마에 자리조차 두지 않은 상태입니다. 확정되면 challenge.schema.json 확장이 필요하고, 확장 시점이 늦을수록 기존 기록과의 호환 처리가 늘어납니다.

D6
다음 차수 범위 지시 대기

후보: 챌린지 선택 UI · 모드2(색상인식) 착수 · 컨셉 이미지 적용 · 서브셋 문법 확장 · 학생 화면 온보딩(조작 안내).

권장: 컨셉 이미지 적용을 먼저. 지금 UI가 임시 팔레트라 이후 작업이 모두 재작업 대상이 됩니다.

D7
컨셉 이미지 전달 시점 대기

도착하면 tokens.css 1개 파일과 에셋 슬롯 경로만 교체하면 됩니다. 코드 수정은 필요 없습니다.

04범위 준수 확인

구현하지 않음 — 서버·DB·AWS, 리더보드, 과제 제출, 실패 판정·페널티·시도 종료, 모드2·3, 카메라 미니창, 리플레이 녹화, 챌린지 선택 UI, 컨셉 이미지 적용, 서브셋 문법 확장.

원칙 준수 — 결정론 유지(배속·프레임레이트가 랩타임에 영향 없음) · 챌린지=데이터 · 하드삭제 없음(이력 삭제 경로 없음, [초기화]는 코드 덮어쓰기) · 수치는 엔진만 생성 · 비주얼은 에셋 슬롯.

결정은 D1~D7 번호로 답해주시면 그대로 반영합니다.
