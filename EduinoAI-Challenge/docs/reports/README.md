# 결과보고 규칙

## 형식 (2차부터 확정)

차수마다 **복사 기능이 있는 보고 페이지**를 만들어 전달한다. 내용은 두 가지만 담는다.

1. **요약** — 무엇을 끝냈는지, 핵심 수치(측정한 값만). 작업 로그·구현 설명은 넣지 않는다.
2. **논의포인트** — 결정이 필요한 항목. `D1`, `D2` … 번호를 붙여 **번호로 회신**받는다.
   각 항목에는 배경 한 줄, 선택지, 권장안을 함께 둔다.

페이지에는 섹션별 복사 버튼과 전체 복사 버튼을 둔다(클립보드 API가 막힌 환경 대비 fallback 포함).
`2026-08-21-phase2.html` 을 템플릿으로 복제해 쓰면 된다.

## 진행 규칙

- **특이사항이 있으면 임의 진행하지 않고 기획자에게 결정을 받는다.**
  판단이 갈리는 지점은 착수 전에 선택지와 권장안을 붙여 질문한다.
- 부득이하게 판단해 진행한 항목은 보고서 논의포인트에 "승인 대기"로 올려 사후 승인을 받는다.
- 수치는 추정하지 않는다. 측정한 값만 적고, 측정 조건(환경·시간)을 함께 쓴다.
