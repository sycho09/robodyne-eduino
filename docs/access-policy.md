# Eduino AI Lab — 무료/유료 분리 기준

## 0. 적용 범위
- 대상 A: 일반 코스 5종 (텍스트, 데이터, 제스처, 생활, 개념)
- 대상 B: 비전·영상처리 코스의 제작 트랙 3종 (이미지 분류, 동작 분류, 음성 분류)
- 제외: 비전 코스의 사전학습 체험 패널 7종 (객체 탐지, 인물 분리, 뼈대, 얼굴 검출, 색 추적, 필터)

## 1. 공통 원칙
- 무료 구간은 "내 데이터로 AI를 학습시켜 결과를 확인하는 경험"까지 도달
- 응용 미션과 평가·관리 기능은 유료
- 무료만으로 1차시(50분) 완결 불가하도록 분량 통제
- 무료 대체재가 존재하는 기능은 잠그지 않음

| 구분 | 구조 특성 | 잠금 축 |
|---|---|---|
| 일반 코스 5종 | 학습 흐름 4단계가 난이도순 배열 | 응용 — 학습 경험은 무료, 응용 미션·평가는 유료 |
| 비전 제작 트랙 3종 | 4단계 전체가 단일 제작 파이프라인 | 폭·산출물 — 파이프라인은 무료, 프리셋·클래스 수·창작 산출물은 유료 |

# Phase 1 — 일반 코스 5종

## 1-1. 접근 정책 (전 코스 공통)

| 학습 흐름 단계 | 무료 개방 | 잠금 |
|---|---|---|
| 1 사전 진단 | OX 문항 전체 + 정답 개수 표시 | 개념별 취약 영역 분석 리포트 |
| 2 이론 학습 | 카드 그리드 + 상세 페이지 전체 | 없음 |
| 3 실습 퀘스트 | 실습 ① · ② 탭 | 실습 ③ 탭 (응용 미션) |
| 4 최종 평가 | 없음 | 문항 · 채점 · 결과 전체 |
| 통합 대시보드 | 없음 | 4단계 진행률 · 성취 종합 |

정책 근거
- 실습 ①은 5개 코스 중 4개가 규칙 기반·사전학습이라 머신러닝 학습 경험이 없음
- 실습 ②의 "내 데이터 수집 → 학습 → 추론"이 제품 가치 명제를 전달하는 지점이므로 무료 개방
- 실습 ①·②는 하나의 학습 흐름으로 연결되어 있어 중간 차단 시 학습 경험 미완성
- 실습 ②의 모델은 세션 내 휘발성이므로 산출물로 보지 않음, 실습 ③의 리포트·증빙이 실제 산출물
- 무료 약 32분 / 유료 포함 약 52분으로 1차시 완결 방지 요건 충족

## 1-2. 코스별 잠금 지점

전 코스 단일 규칙 — 실습 ③ 탭만 잠금

| panel-train | 데이터 수집 → 학습 → 추론 | 무료 |
| panel-demo | 기능 선택 → 임계값 → 혼동행렬 → 최종 매핑 | 잠금 |

### 텍스트 · 언어 AI (/modules/text/)
| 패널 | 내용 | 접근 |
|---|---|---|

| panel-classify | 예문 수집 → 학습 → 분류 | 무료 |
| panel-review | 고객 리뷰 분류기 4스텝 미션 | 잠금 |

### 생활 속 인식 AI (/modules/life/)
| 패널 | 내용 | 접근 |
|---|---|---|

### 머신러닝 개념 실험실 (/modules/concept/)
| 패널 | 내용 | 접근 |
|---|---|---|
| 실습 ① 분류 경계 그리기 | 지도학습 + 과적합 체험 | 무료 |
| panel-compare | 지도 vs 비지도 비교 | 무료 |
| panel-valid | 라벨 은닉 → 군집화 → 정답 대조 → 과적합 정리 | 잠금 |

### 데이터 · 예측 AI (AIoT) (/modules/data/)
| 패널 | 내용 | 접근 |
|---|---|---|
| panel-explore | 변수 조합 → 상관 발견 → 제3변수 통제 → 상관 vs 인과 리포트 | 무료 |
| 실습 ② 예측해보기 | 회귀 모델 학습 | 무료 |
| panel-cluster | 고객 데이터 → K-means → 세그먼트 네이밍 → 예산 배분 | 잠금 |

- panel-explore의 분석 리포트는 개념 결론이며 실무 산출물이 아니므로 무료
- panel-cluster의 마케팅 예산 배분이 실무 산출물에 해당하므로 잠금
- 스텝 단위 차단 없음, 전 코스와 동일하게 탭 단위로 처리

## 1-3. 표시 정책
- 잠금 탭은 숨김 금지, 라벨은 선명하게 유지한 상태로 잠금 표시만 부착
- 잠금 화면에는 해당 응용 미션의 산출물 미리보기 노출 (리포트 썸네일 등)
- 실습 ② 완료 시점에 잔여 분량 안내 표시
  - 문구 예시: 여기까지가 1차시 분량의 약 3분의 2입니다
- 사이드바 학습 흐름 4 최종 평가에 잠금 표시
- 사이드바 코스 목록 5종에는 잠금 표시 없음 (코스별 개별 판매 구조)

# Phase 2 — 비전 제작 트랙 3종

## 2-1. 접근 정책 (3트랙 공통)

| 항목 | 무료 | 잠금 |
|---|---|---|
| 파이프라인 4단계 | 전체 개방 | — |
| 클래스 수 | 2개까지 | 3~4개 |
| 학습 횟수(epochs) | 기본값 고정, 조작 불가 | 조작 가능 |
| 학습곡선 | 개방 | — |
| 혼동행렬 | — | 잠금 |
| 데이터 코치 | 개방 | — |
| 이론 학습 | 개방 | — |
| 추론·평가 | 개방 | — |
| 이미지 저장하기 | 개방 | — |
| AI 상상보드 만들기 | — | 잠금 |
| 내 AI 캐릭터 카드 만들기 | — | 잠금 |
| 정확도 챌린지 | — | 잠금 |
| 내 미션함 · 미션 제출하기 | — | 잠금 |
| 내 현황 대시보드 | — | 잠금 |

정책 근거
- 학습곡선을 무료로 두는 이유는 학습 진행 피드백이 완주에 필수이기 때문
- 혼동행렬을 유료로 두는 이유는 오류 원인 진단이 평가 영역이기 때문
- 이미지 저장하기를 무료로 두는 이유는 산출물을 0으로 만들면 성취감이 사라져 전환 동인이 약화되기 때문
- 일반 코스와 정합 — 제작 경험은 무료, 창작 산출물·평가·관리는 유료

세부 규칙
- epochs 슬라이더는 숨기지 않고 비활성 상태로 노출, 기본값 표시 유지
- 혼동행렬 영역은 자리를 유지한 채 잠금 표시
- 이미지 저장하기는 추론 결과 화면 원본 캡처만 허용, 가공·합성 미포함

## 2-2. 이미지 분류 (panel-direct)

| 프리셋 | 클래스 | 접근 |
|---|---|---|
| 분리수거 분류기 | 캔 · 페트병 · 종이 | 무료 |
| 가위바위보 | 가위 · 바위 · 보 | 무료 |
| 마스크 썼나요? | 썼음 · 안 썼음 | 잠금 |
| 엄지 척 / 아래 | 엄지 척 · 엄지 아래 | 잠금 |
| 자유 주제 | 클래스 1 · 클래스 2 | 잠금 |

선정 근거
- 가위바위보는 즉시성·재미가 높아 첫 Aha 도달 최단
- 분리수거는 수업 연계도가 높아 교사 도입 유인
- 자유 주제를 유료에 두는 것이 핵심, 내가 원하는 것을 만든다는 최대 가치이자 재사용 동인

데이터 상한
- 무료: 클래스당 촬영 30장, 초과 시 촬영 버튼 잠금
- 유료: 상한 없음

## 2-3. 동작 분류 (sub-pose)

현재 상태
- 시나리오 프리셋 UI 없음, 안내 문구에 예시만 존재(팔 들기, 앉기, T자세)
- 이미지 분류의 프리셋 칩 UI를 재사용해 프리셋 행 신설 필요

| 프리셋 | 클래스 | 접근 |
|---|---|---|
| 팔 들기 / 내리기 | 팔 들기 · 팔 내리기 | 무료 |
| 앉기 / 서기 | 앉음 · 섬 | 무료 |
| 자유 동작 | 클래스 1 · 클래스 2 | 잠금 |

데이터 상한
- 무료: 클래스당 촬영 30장 / 유료: 상한 없음

## 2-4. 음성 분류 (sub-audio)

현재 상태
- 시나리오 프리셋 UI 없음, 안내 문구에 예시만 존재(켜, 꺼, 시작)
- 클래스당 최소 8회 녹음 필요로 진입 부담 최대, 프리셋 신설 필요

| 프리셋 | 클래스 | 접근 |
|---|---|---|
| 켜 / 꺼 | 켜 · 꺼 | 무료 |
| 위 / 아래 | 위 · 아래 | 무료 |
| 자유 명령어 | 클래스 1 · 클래스 2 | 잠금 |

데이터 상한
- 무료: 클래스당 녹음 20회 / 유료: 상한 없음
- 무료 상한을 최소 요구치(8회)의 2배 이상으로 설정해 완주 실패 방지

## 2-5. 표시 정책
- 유료 프리셋 칩은 숨김 금지, 라벨·클래스 설명 선명하게 유지한 상태로 잠금 표시만 부착
- 유료 프리셋 클릭 시 프리셋 미적용, 잠금 화면 표시
- 자유 주제 잠금 화면에 "직접 주제를 정해 나만의 분류기 만들기" 가치 문구 표기
- 클래스 2개 도달 시 클래스 추가 버튼 잠금 전환
- 데이터 상한 도달 시 촬영·녹음 버튼 비활성, 데이터 코치 영역에 안내 문구 표시
  - 문구 예시: 무료 버전은 클래스당 30장까지 모을 수 있어요
- 결과물 만들기 3개 버튼 순서 유지, 이미지 저장하기만 활성

## 3. 공통 제약
- 학습 콘텐츠·모델 로직 수정 금지, 접근 제어는 상위 레이어로만 구현
- 잠금은 렌더링 및 이벤트 차단 방식으로만 구현
- 일반 코스 5종, 비전 3트랙 각각 동일 로직 재사용, 개별 분기 코드 작성 금지
- 비전 코스의 사전학습 체험 패널 7종에는 변경 미적용
- 구매 상태는 단일 소스로 관리, 일반 코스와 비전 코스가 동일 소스 참조
- 개발 검증용으로 URL 쿼리 ?plan=paid 강제 적용 분기 포함

## 4. 검증 항목
- 무료 상태로 5개 코스 + 3트랙 전체 순회 시 진행 불능 지점 없음
- 5개 코스에서 실습 ① · ② 정상 동작, 실습 ③ 탭만 잠금 표시
- 5개 코스에서 실습 ② 모델 학습·추론이 무료 상태로 완주 가능
- 최종 평가 진입 시 잠금 표시
- 3트랙 모두 무료 상태에서 클래스 2개로 파이프라인 4단계 완주 가능
- 동작·음성 트랙 프리셋 UI 신설 및 무료 2종 정상 적용
- 데이터 상한 도달 시 수집 버튼 비활성
- 유료 상태 적용 시 전 항목 정상 접근
- 새로고침 후 잠금 상태 일관 유지
- 사전학습 체험 패널 7종 동작에 회귀 없음
