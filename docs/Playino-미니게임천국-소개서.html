Playino : 미니게임천국

센서를 미니게임으로 배우는 피지컬 코딩 키트

1. 제품 소개

마스코트 EDDIE와 함께 8개 센서를 미니게임으로 익히고, 응용·심화로 나만의 작품까지 완성하는 STEAM 피지컬 코딩 키트입니다. 설치 없이 웹 브라우저로 학습하고, 실물 센서를 직접 제어합니다.

  • 핵심 컨셉 — 센서 1개 = 전용 미니게임 1개. 게임으로 동기부여하고, 이론관(원리) + 체험관(게임)으로 깊이 있게.
  • 대상 — 초등 고학년 ~ 중등 (가정·방과후·학원·학교 교구)
  • 학습 환경 — Chrome / Edge 브라우저 (PC · 노트북 · 크롬북), USB 연결. 설치 불필요, 접속 링크/코드로 입장.
  • 구조 — 메달을 모아 진척 100% 달성 시 졸업.

2. 학습 구성 (3단계)

단계성격내용
1단계 개별학습센서 원리·제어센서별 미니게임 8개 — 게임으로 각 센서를 체득
2단계 응용학습감지 → 동작 (피지컬 컴퓨팅 핵심)입력+출력 조합 작품 4개 — "센서로 읽어 무언가를 움직인다"
3단계 심화학습창작 (브랜드 클라이맥스)나만의 미니 게임기 1개 — 배운 센서로 직접 게임 제작 (졸업 작품)

3. 구성품 리스트

공통 — Arduino Uno(호환) 보드 · Grove Base Shield · USB 케이블 · Grove 케이블 · 수납 박스 · 퀵스타트 가이드(QR)

센서 8종 (출력 4 · 입력 4)

#센서입/출력대표 게임
1LED ×3 (빨강·노랑·초록)출력반짝반짝 라이트쇼
2부저 (Passive)출력멜로디 연주단
3RGB LED출력무지개 물감놀이
4서보 모터 (SG-90)출력행운의 룰렛
5조도센서 (CDS)입력손그림자 마술
6버튼 (택트)입력두더지 잡기
7조이스틱입력별★줍기 대모험
8초음파 거리센서입력손 거리 마법

※ Grove 시스템 기반(무납땜, 케이블 연결식)으로 초·중등도 쉬운 세팅. 무선(BLE) 모듈은 별매 액세서리로 추후 제공. 단가·모델·인증(KC)은 별도 확정.

4. 커리큘럼 소개

① 개별학습 — 센서별 미니게임 8

센서게임장르 / 학습
LED반짝반짝 라이트쇼리듬 · 디지털 출력/타이밍
부저멜로디 연주단리듬 · tone/주파수
RGB LED무지개 물감놀이색 맞추기 · PWM 색 혼합
서보행운의 룰렛타이밍 · 각도 제어
조도(CDS)손그림자 마술반응+생존 · 아날로그 입력(빛)
버튼두더지 잡기연타/반응 · 디지털 입력
조이스틱별★줍기 대모험이동/수집 · 2축 아날로그 입력
초음파손 거리 마법거리 조절 · 비접촉 거리 측정

② 응용학습 — 감지→동작 조합 4

작품센서 조합배우는 핵심
스마트 홈 미니조도 + 초음파 + 서보 + RGB + 부저어두우면 조명 ON, 사람 다가오면 문 열림+알림
비접촉 테레민초음파 + 부저손 거리 → 음정 (아날로그 매핑)
우주 슈팅조이스틱 + RGB/LED이동·발사 (입력으로 출력 제어)
자동 관문버튼/초음파 + 서보감지 시 모터 작동 (조건→동작)

③ 심화학습 — 졸업 작품 1

작품센서 조합내용
🎮 나만의 미니 게임기조이스틱 + 버튼 + RGB + 부저아두이노가 게임 컨트롤러가 되어, 배운 센서로 직접 미니게임을 완성하는 졸업 작품
